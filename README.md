# SAIR Consultores

Sitio y guía de marca de **SAIR Consultores** (Soluciones Académicas Innovadoras y Responsables),
preparados por [16 Ball Creations](https://16ballcreations.com).

- Guía de marca: `/guia/` — https://16ballcreations.github.io/sair-consultores/guia/
- Sitio: `/` (en construcción; hoy es una portada provisional)

HTML y CSS sin frameworks, publicado con GitHub Pages desde la rama `main`.

## Estructura

| Ruta | Qué es |
|---|---|
| `assets/css/sair.css` | **El sistema de marca**: colores, tipografía, espacios, formas y componentes base. Lo usan la guía y el sitio |
| `guia/` | La guía de marca, como página web con forma de documento |
| `assets/img/` | Logotipo y fotos |
| `index.html` | Portada del sitio |

## Reglas para trabajar en este repositorio

- Los valores de marca viven en `assets/css/sair.css`. Si cambias uno, actualiza la guía.
- El tono, los nombres oficiales y los textos están en la guía (secciones 07 a 10). Úsalos tal cual.
- Este repositorio es **público**: aquí no van auditorías, notas internas ni datos de contacto personales.
  Esos documentos están fuera del repositorio, en la carpeta privada del cliente de 16 Ball Creations.
